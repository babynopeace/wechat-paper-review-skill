# Repository guidance

This repository contains the Codex skill at `.agents/skills/wechat-paper-review/SKILL.md`.

- When updating the workflow, read `SKILL.md` and keep supporting references/scripts synchronized.
- Run `python -m unittest discover -s tests -v` before committing.
- Never commit user-provided article PDFs, proprietary full-text documents, personal Word files, extracted figures, private credentials, or user outputs.
- Do not fabricate scientific evidence or citation values. Human/model review is required beyond programmatic checks.
- Publishing source-code to GitHub is separate from publishing copyrighted paper figures; figure redistribution requires separate rights verification.
